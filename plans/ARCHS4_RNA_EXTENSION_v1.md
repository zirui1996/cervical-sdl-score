# Additional uniformly processed RNA cohort

Written 2026-10-29 after the official ARCHS4 metadata API confirmed all 24 GSM accessions for GSE147009, before requesting its expression data or inspecting new-cohort target statistics. The ten-gene program and all thirteen union genes are already frozen. No additional targets will be selected.

GSE147009 used ribosomal-RNA-depleted sequencing of cervical tissues: six HPV-negative normal, six HPV16-positive non-lesional, six HPV16-positive HSIL and six HPV16-positive SCC. The GEO supplementary matrix contains circRNA rather than the required host-gene matrix. The official ARCHS4 API provides uniformly processed host-gene counts from the same public RNA-seq samples, so request all 24 samples, retain the exact returned matrix and metadata, and verify all expected samples are present. This is an alternative processing resource for one source cohort, not 24 additional patients or an independent experiment relative to GSE147009.

If data are available, compare all six HSIL with all six SCC using the same frozen score and target definitions, log2(estimated-count CPM+1), HC3 and t inference. ARCHS4 uses a Kallisto-based processing pipeline; do not describe these estimates as author-provided STAR/HTSeq integer counts or as an exact reanalysis of author circRNA expression. Inspect source column totals and gene identifiers, retain processing-version/service-date information, and report any absent samples or unusable score coverage before inference. No expression-based exclusion or replacement is allowed.

Keep the two-study testing families previously fixed for GSE166466/GSE149763 as historical analyses. Add Holm correction across all three new studies for the program (three tests), across all union genes in the third study, and conservatively across every union-gene test plus program test in all three new studies (42 if 13 union genes and all programs are measurable). Non-estimable targets receive P=1. Report all studies and all corrections; do not declare a candidate confirmed by an uncorrected P or by choosing the most favorable family.

Stage-context comparisons can include HPV16-positive histologically normal samples, which are distinct from cervicitis and HPV-negative normal tissue. This does not make the cross-sectional data a longitudinal transition study. Any lack of transfer must remain in the final route decision.
