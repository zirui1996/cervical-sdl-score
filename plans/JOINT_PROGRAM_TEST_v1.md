# Fixed joint-discovery expression program

Written 2026-10-29 after the ten-gene joint-discovery list was locked and before any of these genes or their phenotype associations were inspected in the new tissue cohorts. Only new-file metadata and a count-file header/three non-target rows have been previewed for parsing. The ranking rule was written before that format preview; its implementation required a pandas-index bug fix without changing the rule. Keep this timing note with the analysis record.

This is a new, explicitly exploratory program-level extension. It does not rewrite the original top-five failure or the later three-gene selection. A fixed program can test whether a coordinated expression pattern transfers better than individual single-study hits, without training a classifier in the small new datasets.

Use all ten genes from `meta_discovery_candidate_lock.json`, equal weight, direction fixed by the three old studies. No target substitution, validation-based weighting, cutpoint fitting or outcome-dependent gene removal. Per sample, rank genes over the original common-platform symbol universe intersected with the measured matrix. Program score is the mean of signed fractional ranks of the frozen targets. A higher score is oriented to the old-study invasive state. All ten happen to be negative in discovery; therefore a higher score means lower expression of that fixed set, not biologically proven dedifferentiation. Require at least eight measured targets; otherwise report unscorable. Record complete and missing target lists. Sensitivity requiring all ten must be reported when possible.

In GSE166466 and GSE149763, standardize the score within the primary analyzed samples and fit score ~ group + Composite with HC3/t inference. Test one fixed program per study, use Holm across the two new studies, require positive coefficient for directional support. Report unadjusted score contrasts as sensitivities. Also report a conservative Holm family containing both program tests and every union-gene test across both new studies. Do not call an uncorrected P or a favorable sensitivity confirmation. Old-study effect sizes are development descriptions only.

Use existing normals and new GSE51993 as stage-context analyses, GSE75132 as a distinct, provisional endpoint-transfer check subject to label audit, and specimen-by-lineage summaries in GSE208653 to investigate cellular source. Do not call this program a diagnostic assay, cancer progression predictor or causal mechanism. If new evidence does not support the program, retain the negative result and reassess the route rather than choose a different score.
