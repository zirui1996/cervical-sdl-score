# Stage boundary clarification, version 1

Written on 2026-10-29 before executing this extension. This is a post hoc clarification of the already selected fixed ten-gene score, not a new independent validation or a new programme selection exercise.

Question: do the data support a difference specifically at the HSIL/invasion boundary, or only a contrast between sampled HSIL and established invasive cancers? Preserve all previous score definitions, failed candidates, independent RNA results, and multiplicity families.

1. GSE63514: include the laser-captured Normal, CIN1, CIN2, CIN3 and invasive Cancer samples; exclude the eight whole-section cancers as in the original primary analysis. Use stage as five categories, not a numerical time axis. Recompute only the original fixed score and Composite proliferation score, with no gene or direction changes. Model standardized programme score on stage indicators plus standardized Composite. Use HC3 covariance and residual-degrees-of-freedom t inference. Report four adjacent contrasts and three direct contrasts of Cancer-minus-CIN3 against each earlier adjacent contrast. These seven tests are developmental stage clarification.
2. GSE223804: use original pathology titles to separate five IA1/IA2 cancers from four IB-or-higher cancers and four HSIL specimens. Exclude true CIN1 and normal samples from this model. Model the three categories plus Composite using the same inference as above. Test IA-minus-HSIL, IBplus-minus-HSIL and IBplus-minus-IA. Repeat the same three comparisons using the existing ARCHS4-sum reprocessing of these same patients, explicitly a processing sensitivity and not another study.
3. Apply Holm correction jointly to the 13 fixed-score tests in this extension. Show all estimates, confidence intervals, sample counts and adjusted p-values. The same RNA patients tested under two processing routes are dependent; Holm does not require independence, and the dependence must remain explicit.
4. Check matrix/sample identity, exact group counts, design rank, score completeness, and contrast algebra. No cell-level tests, causal interpretation, diagnostic cutoffs, survival/drug extensions, or data-dependent gene replacement. Non-significance does not prove equality, absence of early effects, or equivalence between stages.

Interpretation gate: strong array stage patterns alone cannot establish future progression, the timing of invasion, or cross-platform RNA transportability. Any unsupported microinvasion claim must be removed. These analyses cannot fill the independent bulk-RNA or pathology-annotated spatial evidence gaps.
